# Diagnose Analysis Objects

Generic function for diagnosing analysis objects.

See documentation for specific methods:

- [`diagnose.cmdstan_mcmc_analysis()`](https://poissonconsulting.github.io/smbr/reference/diagnose.cmdstan_mcmc_analysis.md)

## Usage

``` r
diagnose(x, ...)
```

## Arguments

- x:

  An analysis object.

- ...:

  Additional arguments passed to methods.

## Value

Diagnostic output (format depends on the analysis type).
